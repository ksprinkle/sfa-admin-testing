** PS Script Quiet Start Back & Front end.

Done. I added the one-click quiet launcher script at start-dev-quiet.ps1.

What it does:

Starts backend in quiet mode:
uvicorn with no access logs and warning-level logs
Starts frontend in quieter mode:
Vite with warn log level
Opens each in its own PowerShell window by default
How to run:

From repo root:
powershell -ExecutionPolicy Bypass -File start-dev-quiet.ps1
Optional mode:

Keep backend in current terminal and only open frontend in a new window:
powershell -ExecutionPolicy Bypass -File start-dev-quiet.ps1 -NoNewWindows
