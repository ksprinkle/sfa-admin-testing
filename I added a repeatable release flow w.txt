I added a repeatable release flow with two PowerShell scripts:

release-preflight.ps1
create-release-tag.ps1
What they do:

release-preflight.ps1
Fails if git working tree is not clean
Runs backend syntax check via python -m compileall -q api
Ensures frontend deps exist and runs frontend build
Optional flag to skip frontend build: -SkipFrontendBuild
create-release-tag.ps1
Runs preflight automatically (unless skipped)
Creates annotated git tag
Optional push to origin
Optional skip flags:
-SkipPreflight
-SkipFrontendBuild
-Push
I also syntax-validated both scripts in terminal without executing release actions.

How to use:

Run preflight only:
powershell -ExecutionPolicy Bypass -File release-preflight.ps1

Create a local release tag:
powershell -ExecutionPolicy Bypass -File create-release-tag.ps1 -Version v2026.04.22-1

Create and push release tag:
powershell -ExecutionPolicy Bypass -File create-release-tag.ps1 -Version v2026.04.22-1 -Push

Tag without frontend build (faster, if already built):
powershell -ExecutionPolicy Bypass -File create-release-tag.ps1 -Version v2026.04.22-1 -SkipFrontendBuild
